## 기존 포트폴리오와의 차이

기존 자료는 서비스 기능과 기술 구성을 폭넓게 설명합니다. 새 자료는 아래 순서를 고정해 채용 담당자가 기획자의 판단을 빠르게 확인하도록 구성합니다.

1. 문제 신호와 원인
2. 가설과 성공 기준
3. 핵심 PRD와 우선순위
4. 출시 과정의 제약과 트레이드오프
5. 결과, 한계, 다음 검증

사용자 성과가 충분히 쌓이지 않은 항목은 시스템 검증과 분리해 표시합니다. 방문자, 리텐션, 만족도처럼 아직 측정하지 않은 수치는 만들지 않습니다.
